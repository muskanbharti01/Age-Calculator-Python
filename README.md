## Age Calculator 

    A simple Python program that calculates the user's age based on their birth year. 

## Features 

    Takes birth year as input
    Calculates age
    Displays the result
  
## Technologies Used
    Python
    
  ## How to Run
  
      1. Run the program
      2. Enter your birth year
      3. View your age
  ## Example
       Input: 2004
       Output: Your age is: 22
